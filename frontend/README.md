# Stylentra — E-Commerce Website

**Developed by Aditya Kumar**

A modern e-commerce web application built using React.js and other web technologies. Stylentra provides a user-friendly shopping experience with product browsing, cart management, wishlist functionality, and order management.

## 🚀 Features

- Browse and explore products
- Search and filter products
- Add products to the shopping cart
- Add and remove wishlist items
- User login and profile management
- Place orders and view order history
- Responsive user interface
- Toast notifications for user actions

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Aditya957258/EcommerceWebsite.git
cd EcommerceWebsite
```

### 2. Install frontend dependencies

```bash
cd frontend
npm install
```

### 3. Start the frontend

```bash
npm run dev
```

### 4. Start the backend

If your project includes a backend, open another terminal:

```bash
cd backend
npm install
npm run dev
```

Configure environment variables and database credentials according to your local setup. Never commit passwords, API keys, or `.env` secrets.
